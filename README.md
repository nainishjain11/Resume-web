# Personal Resume Website - Nainish Jain

This is a multi-page personal resume and portfolio website created using foundational HTML5, CSS3, and vanilla JavaScript. It presents my academic journey at IIM Bangalore and Chartered Accountancy (ICAI), documented competition victories, leadership roles, and strategic areas of interest.

## Pages Included
- `index.html` - Cover page with introduction, featured ISB session photo, and navigation cards.
- `about.html` - Background story, personal perspective, and interactive trivia fact generator.
- `education.html` - Summary table and details of academic credentials.
- `achievements.html` - Featured ISB pitch case study, competition wins, and leadership spotlight.
- `interests.html` - Focus topics and active study explorations.
- `contact.html` - Direct contact channels, CV download link, and message form.
- `404.html` - Fallback page for non-existent routes.

## CSS Concepts Applied
- **Typography:** Custom Google Fonts (`Space Grotesk`, `DM Sans`, and `Space Mono`).
- **Color Palette:** Warm dark theme (`#111210` background, `#1a1b18` cards, `#f4f1ea` text, `#f5b700` electric mustard accent, `#ff6b35` coral secondary) with light mode toggle.
- **CSS Box Model:** Universal reset with `box-sizing: border-box`, tactile offset shadows, and borders.
- **Flexbox Layout:** 1D alignment for the sticky navigation bar, button groups, and footer.
- **CSS Grid Layout:** 2D responsive grids (`grid-2`, `grid-3`, `grid-4`, `hero-split`, and `spotlight-card`) using `repeat()` and `fr` units.
- **Responsive Design:** Media queries (`@media (max-width: 768px)`) for mobile layouts.
